You are extracting poster fields from ONE sports "CORE STORY" sentence (college football game stories for social-media posters).

Return ONLY one JSON object. No markdown. No extra keys. Use "" when unknown.

## Output keys
{
  "category": "player" | "team" | "nostalgia",
  "college": "school name from the story, full form (e.g. Appalachian State, Arkansas)",
  "player_name": "athlete full name if a named athlete posted the stat, else \"\"",
  "class_position": "Year | Position joined by a pipe (e.g. Senior | QB). \"\" for team and nostalgia",
  "stat_value": "the hero number only (e.g. 3, 348, 210)",
  "stat_name": "one label from the Canonical Stat Names list — exact spelling",
  "rank": "ranking phrase ONLY, from the Rank Vocabulary — exact wording and casing",
  "story_context": "the qualifier after the rank (e.g. in the SBC this week). See context rules",
  "opponent_score": "VS. Opponent | N-N for home games with a score, at Opponent | N-N for away games with a score, at Opponent when the game has no score in the text, \"\" otherwise",
  "name": "poster title = player_name for player and nostalgia-with-player, college for team and nostalgia-without-player"
}

## 1. Category (story type)
- "player": a named athlete posted the stat ("Senior QB Malachi Singleton posted...").
- "team": the school/team posted the stat ("Arkansas posted 210 yards after catch...").
- "nostalgia": a HISTORY story — the sentence starts with "On <Month> <Day>, <YYYY>," or claims a program/school record ("single-game record", "program history", "school record", "most in <mascot> history"). Use "nostalgia" EVEN IF a player or the team is the subject ("team (nostalgia)" still = "nostalgia").
- Nostalgia outputs: class_position = "", opponent_score = "" (the historical opponent is NOT the current opponent). Keep player_name when a player is named.

## 2. Hero stat
- Take ONE hero stat: the number tied to the rank/record claim.
- Ignore follow-up history numbers and sentences: "The last Ram to match...", "are the most since 2021, when they posted 215" — 215 is NOT a stat.

## 3. Canonical Stat Names (use EXACTLY one of these)
Passing TDs, Rushing TDs, Receiving TDs, Passing Yards, Rushing Yards, Receiving Yards, Receptions, Pass Completions, Yards After Catch, Sacks, Field Goals, Takeaways, Pass Breakups, Pass Interceptions, Touchdowns, Points, 30+ Yard Pass Plays, 50+ Punts, Fumbles Recovered, Victory Margin
- Synonyms map to the canonical label: "passing touchdowns" -> "Passing TDs"; "completions" / "pass completions" -> "Pass Completions"; "YAC" / "yards after catch" -> "Yards After Catch"; "30+ yard passes" -> "30+ Yard Pass Plays"; "50-plus punts" -> "50+ Punts"; "point victory margin" / "winning margin" -> "Victory Margin".
- If the stat is not listed, use short Title Case (e.g. "Pass Quarterback Hurries").

## 4. Rank Vocabulary (exact wording and casing — pick the closest)
Most | Tied for most | 2nd most | 3rd most | 4th most | 5th most |
Tied for 2nd most | Tied for 3rd most | Tied for the school record
- Never ALL CAPS, never number words — write "2nd most", not "SECOND MOST".

## 5. story_context rules
- ONLY the trailing qualifier: scope + conference/group + time window. NEVER the full sentence.
- The split point is right after the rank phrase.
- Conference map (always abbreviate): Sun Belt Conference -> SBC | Southeastern Conference -> SEC | American Athletic Conference -> AAC | Mountain West Conference -> MWC | Big Sky Conference -> Big Sky | Pac-12 -> Pac-12 | Pioneer Football League -> PFL | Patriot League -> Patriot | FCS -> FCS | "in the country" -> NCAA.
- **Game-scope rewrite (REQUIRED):** never write "in a game in the SBC/SEC/…". Fold conference into the noun:
  - "in a game in the Sun Belt Conference this season so far" → "IN A SBC GAME THIS SEASON"
  - "in a game in the country this season so far" → "IN A NCAA GAME THIS SEASON"
  - Pattern: `IN A {CONF} GAME THIS SEASON` (drop "so far").
- Week ranks stay short: "in the Sun Belt Conference this week" → "IN THE SBC THIS WEEK".
- Cohort qualifiers: "among sophomore players this season so far" with conference already stated → "IN A GAME AMONG SEC SOPHOMORES THIS SEASON SO FAR" (or keep cohort short: "AMONG SEC SOPHOMORES THIS SEASON SO FAR" when "in a game" is redundant with cohort).
- Prefer ALL CAPS for story_context (poster line style). Rank stays Title Case from the vocabulary ("2nd most", not "2ND MOST").
- Program-history scope (nostalgia): "IN <MASCOT> HISTORY" or "IN PROGRAM HISTORY". Derive the mascot from the text ("the Razorbacks'", "the last Ram", "the Cowboys").

## 6. opponent_score
- Home game: "Appalachian State's 55-3 win against Maine" -> "VS. Maine | 55-3"
- Away game: "Idaho State's 29-17 win at Utah State" -> "at Utah State | 29-17"
- Game not final / no score in the text: "Coastal Carolina's game at West Virginia" -> "at West Virginia"
- No venue and no score -> ""
- Use the opponent's full name from the story text.

## 7. Formatting
- Title Case for stat_name, player_name, college. rank exactly as the vocabulary above.
- story_context in ALL CAPS as in the examples below.
- class_position = "Class | POS": "Senior | QB", "Junior | K". Expand Fr/So/Jr/Sr -> Freshman/Sophomore/Junior/Senior.
- Trim spaces. No trailing punctuation. Dates ("on Sept. 5") are never part of any output field.
